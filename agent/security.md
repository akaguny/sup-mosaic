# Безопасность — состояние и принятые риски

Служебный документ агента. Отчёты аудита — [audit/](audit/): [1](audit/audit-1.md) (до правок), [2](audit/audit-2.md) (после SRI и санитайзера), [3](audit/audit-3.md) (проверка правок).

## Что сделано

- Сторонние библиотеки с cdnjs подключаются только с `integrity` (SHA-384) + `crossorigin="anonymous"` + `referrerpolicy="no-referrer"`: jsPDF 4.2.1 в `index.html`, marked 18.1.1 и DOMPurify 3.4.17 в `docs.html`. Хеши закреплены по файлам, которые реально отдаёт CDN; при обновлении версии хеш пересчитать.
- Markdown документации проходит `DOMPurify.sanitize` с `FORBID_TAGS: ["style","form","input","button","textarea","select"]` и `FORBID_ATTR: ["style"]`; ссылки с небезопасными схемами теряют `href`; внешние открываются с `rel="noopener"`.
- `localStorage` считается недоверенным: `cleanSheets` / `cleanSwap` / `cleanCw` / `cleanSettings` пересобирают состояние (клампы координат и настроек, отбраковка неизвестных досок и цветов, лимиты 500 листов × 200 досок), словари `PAL` и `byId` созданы через `Object.create(null)`.
- Экспорт PDF собирается внутри `try`; вне хост-рантайма (`window.claude`) файл сохраняется обычной загрузкой браузера, в хост-песочнице без `downloads` выдаётся честная ошибка, а не ложное «готово».

## Принятые риски

- **CSP не задан.** Мета-политика ломает рантайм артефакта claude.ai, а GitHub Pages не даёт заголовков для статики. Остаётся внешний `<img>` из недоверенного markdown (трекинг), кликджекинг не закрыт. Ущерб ограничен: приложение не работает с чужими данными и никуда их не отправляет.
- **Google Fonts** получает IP и User-Agent посетителя. Полностью локальный вариант — положить woff2 в репозиторий и убрать `<link>` на fonts.googleapis.com.
- **Все `*.github.io` в одном origin:** другой Pages-проект того же аккаунта видит `localStorage` этого приложения. Снимается только отдельным доменом (CNAME).
- **Библиотеки остаются на CDN** (локального вендоринга нет по решению пользователя) — целостность держится на SRI, доступность зависит от cdnjs.
- **Python-инструменты `tools/`** разбирают недоверенные PDF и фото: pdfminer.six до 20251230 (CVE-2025-64512, CVE-2025-70559) и Pillow на очень больших изображениях. Запускать в отдельном venv или контейнере, версии держать свежими.
