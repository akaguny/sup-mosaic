# Форматы данных

Все данные — в `data/`, код их только читает. Для новой доски обычно меняются два файла: `art.json` (рисунок) и `catalog.json` (запись каталога). После ручной правки проверьте, что JSON валиден: при ошибке страница показывает плашку с именем файла.

## data/catalog.json — доски

Массив записей, одна строка — одна доска:

```json
{"brand": "Gladiator", "model": "PRO (2022)", "kind": "allround",
 "sizes": [["10'4", 30], ["10'6", 32]],
 "colors": {"rail": "S158", "deck": "S158", "pad": "S146", "acc": "S01", "acc2": "S58"},
 "colorsFrom": "keychain", "style": "band bungee", "year": "2022",
 "keychain": "PRO 11.4 2022–2025 · брелок"}
```

| Поле | Значение |
|---|---|
| `brand`, `model` | бренд и модель; вместе дают id доски |
| `kind` | `allround`, `touring`, `race`, `surf`, `yoga`, `fishing` — профиль носа и хвоста, длина брелока |
| `sizes` | `[длина, ширина″]`; длина строкой `"12'6"`. У брелока `[]` |
| `colors` | роли → код Artkal S (`"S103"`) или короткий ключ из `colors.json` (`"NB"`). `acc2` необязателен |
| `colorsFrom` | `photo`, `keychain`, `photo?`, `approx` — см. [Цвета](../docs/colors.md); `colorsNote` — пояснение (например «фото сбоку») |
| `style` | признаки типового трафарета через пробел (`band`, `band2`, `bungee`, `dots`, `spine`, `center`) или `art:<ключ>` — рисунок из `art.json` |
| `year` | коллекция, для фильтра по годам |
| `keychain` | модель брелока по фото того же бренда; без него приложение строит типовой брелок |

## data/art.json — рисунки по фото

```json
"pro22akey": {"photo": "gladiator-pro-2022-allround.jpg",
  "only": {"17x9": "32″ → 8,5×4,5 см на midi"},
  "grids": {"17x9": ["...rrr...", ".rdddddr.", "…"]}}
```

- `grids` — сетки по размеру `"рядыxстолбцы"`; строки от носа к хвосту, каждая ровно в ширину сетки.
- `only` — это брелок: своя сетка и подпись размера, которая видна в каталоге и на листе.
- Без `only` — полноразмерный рисунок: ключи сеток совпадают с размерами, которые приложение считает из `sizes` (около 5,8″ длины на бусину: 12'6″ × 32″ → 26 × 6); для остальных размеров строится типовой трафарет по `fallback`.
- Один рисунок может использоваться несколькими записями каталога с разными цветами (перекраски: Origin SC, RNT, ONE).

Символы сетки:

| Символ | Роль | Символ | Роль |
|---|---|---|---|
| `r` | кант | `a` | акцент |
| `d` | дека | `b` | акцент 2 |
| `p` | пэд | `o` | бусина под кольцо (цвет канта, обводится красным) |
| `.` | пусто | | |

## data/colors.json — короткие ключи

`{"NB": "S64", "OR": "S56", …}` — для старых записей каталога. В новых пишите код Artkal напрямую.

## data/palettes.json — наборы бусин

`sets` — подписи наборов; `colors` — набор → список `[код, имя, hex]`. Artkal S — основной, коды без префикса (`S01`); остальные внутри приложения получают префикс набора (`hama:H01`).

## data/rename.json — переименования

Пары `[старый префикс id, новый префикс id]`. id доски на листе — `бренд|модель|NxW` с `_` вместо пробелов, например `Gladiator|PRO_(2022)|22x6` (10′6″ × 32″). Когда модель переименована или сетка удалена, добавьте пару — иначе сохранённые листы и профили потеряют доску (приложение молча уберёт её с листа).
