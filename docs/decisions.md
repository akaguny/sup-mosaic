# Решения и вопросы

## Решения пользователя

- Карточка gladiator.ru «ELITE 12.6T (2022)» без «новинка» — это доска, которую пользователь зовёт **Elite 12.6T 2021**; в каталоге — «ELITE LT / S / T (2021)». «Новинка 2026» — другой дизайн.
- Брелок — узнаваемая карикатура, пропорции можно преувеличивать. Ширина брелока по ширине доски: до 26″ — 5, 27–29″ — 7, 30–32″ — 9, от 33″ — 11 бусин. Длина: race 21, touring 19, allround 17.
- 31″ Elite 12.6T → 19×9 (заменил 17×5 и 15×5), 24″ Elite 12.6R → 21×5. Вариант 21×4 и 21×11 отклонены.
- Кольцо — в середине последнего ряда хвоста.
- Пятая роль «Акцент 2» добавлена для досок, где без неё не передать рисунок (Elite 2026, PRO, ORIGIN).
- Брелок есть у каждой доски каталога (пожелание пользователя 10.10.2026). Где рисунка по фото ещё нет, брелок строится автоматически — «типовой» (`js/catalog.js`, блок KEY_ROWS): ширина по медиане ширин доски, длина по типу, узор из признаков style. Типовые помечены в каталоге и заменяются по мере рисования по фото (запись `keychain` в каталоге отключает типовой).
- Dragon 22.0 — исключение из правила длины: 27×9 вместо 19×11, иначе 22-футовая доска не читается длинной. BIG SUP 17.0 (60″) оставлен 11 в ширину по правилу.
- Близнецы (Origin SC, RNT, Wind, River, BIG SUP) — те же сетки Origin 2022/2026 в своих цветах; ONE Red/Lime/White — один рисунок, три расцветки.
- Цвета каталога приведены в соответствие с фото (10.10.2026): у Gladiator — те же, что у выверенного брелока; у остальных брендов роли назначены вручную по фото (`tools/colors_by_photo.py`). В интерфейсе у доски видно происхождение цветов, «≈ цвета» — фото нет или оно неполное.
- Приложение пересобрано в многофайловый проект (данные в JSON, код по модулям, инструменты в tools/) — по просьбе пользователя, 10.10.2026.

## Открытые вопросы

- Для №99 JS GQ Orange в выгрузке фото весла, а для №95 Dark Queen — вид сбоку с красным кантом: цвета деки и пэда взяты по названию. Нужны фото сверху.
- ONE: «G» в носу в 11 бусинах читается как крупный значок, но не как буква — если не узнаётся, заменить на сплошной цветной нос.
- SPECIAL Duo: косые красно-синие блоки упрощены сильнее всего — сверить с фото.
- Dragon 22.0 сделан 27×9 (исключение из правила длины), BIG SUP 17.0 — 17×11.
- Elite 14.0GT 2026 сделан 21×9 (длинная, тип race в каталоге); если GT считать турингом — 19×9.
- Для PRO 2022–2025 корпус S158 Pepper почти чёрный; если хочется заметно синего — S144 Marine.
- Полноразмерный ELITE 14'0×30 (2021) нарисован по фото 12'6 — отдельного фото нет.
