# Устройство приложения

Многофайловый артефакт claude.ai без сборки: обычные скрипты в общей глобальной области (не ES-модули), данные в JSON.

## Загрузка

`index.html` подключает `styles.css`, jsPDF 2.5.1 с cdnjs и `js/boot.js`. Загрузчик:

1. читает `data/palettes.json`, `colors.json`, `art.json`, `catalog.json`, `rename.json` в `window.DATA`;
2. по порядку подключает модули: `palette → catalog → state → layout → draw → ui → app` — каждый следующий опирается на глобальные имена предыдущих (`PAL`, `ST`, `S`, `sel` и т. д.);
3. при ошибке загрузки показывает плашку с именем файла и останавливается.

## Модули

| Файл | Что делает |
|---|---|
| `js/palette.js` | `PAL` — все цвета всех наборов; `conv(id)` переводит цвет каталога в выбранный набор по Lab; `rgb`, `lum`, `mix` |
| `js/catalog.js` | разворачивает каталог в `ST` — список трафаретов: размеры из дюймов (`dims`), типовые сетки (`shape`, `makeGrid`), рисунки по фото (`artGrid`), типовые брелоки (`KEY_ROWS`, `keyWidth`), ссылки доска → брелок (`keyId`), происхождение цветов (`CF`); `byId`; переименования (`alias`, `fixIds`) |
| `js/state.js` | состояние `S` (настройки, листы, замены цветов), размещение на поле (`findSpot`, `overlaps`, `inField`), клетки доски с учётом поворота (`cellsOf`), подсчёт бусин (`tally`) |
| `js/layout.js` | раскладка листа в миллиметрах (`geom`), ячейки под бусины вне поля: кружки (`slots`, `planCells`) или квадраты под коробочки (`boxesPlan`) |
| `js/draw.js` | `drawSheet` — один код рисования для экрана (`canvasPen`) и PDF (`pdfPen`) |
| `js/ui.js` | лист на экране, панель досок, легенда и замена цветов, расцветки, каталог и фильтры, листы, перетаскивание |
| `js/app.js` | профили печати, экспорт PDF, запуск `start()` |

Запись `ST`: `{id, b, m, k, n, w, sz, y, g, roles, used, photo, key, auto, full, keyId, cf, cnote}` — сетка `g` из ролей (`rail`, `deck`, `pad`, `acc`, `acc2`, `ring`), `used` — какие роли есть в сетке (их и показывает «Расцветка доски»).

## Хранение

| Что | Где | Ключ |
|---|---|---|
| текущие листы (черновик) | localStorage браузера | `sup-mosaic-draft-v3` |
| профили печати и расцветки | возможность `db`, коллекция `data/users/<uid>` (`kind: "profile"` / `"colorway"`); без входа — localStorage | `sup-mosaic-profiles`, `sup-mosaic-colorways` |
| PDF | возможность `downloads` | — |

Возможности артефакта: `db`, `downloads`, `user`. При публикации их не передают — они сохраняются от прошлой версии.

При запуске черновик проходит через `fixIds` (переименования), доски, которых больше нет в каталоге, убираются с листа.

## Печать

Лист рисуется в миллиметрах: поле в центре по ширине, шапка 13 мм, подвал 9 мм с отрезком 50 мм для проверки масштаба. Подписи в PDF латиницей (Helvetica). Бусина под кольцо обводится красным, в подвале появляется пояснение.

## Ограничения среды

Страница работает в защищённой рамке claude.ai: внешние скрипты только с разрешённых CDN, печать браузером недоступна (поэтому PDF), загрузка файлов — через возможность `downloads`. В песочнице агента Google Fonts и cdnjs недоступны — ошибки их загрузки при проверке ожидаемы.
