# SUP-мозаика

Генератор трафаретов термомозаики для SUP-досок: полноразмерные модели и брелоки. Доски кладутся на поле штырьков, приложение считает бусины по цветам, рисует под них ячейки на свободном месте листа и сохраняет PDF для печати в масштабе 1:1.

Приложение: https://akaguny.github.io/sup-mosaic/ · исходный артефакт: https://claude.ai/artifact/VMAbzmZZjhK3KREbrzP7yL · документация в нём же — ссылка «Документация» в шапке.

English overview: [README.en.md](README.en.md).

## Что внутри

| | |
|---|---|
| Доски | 104 полноразмерные модели 8 брендов: Gladiator (48), Aqua Marina (15), JS (13), Starboard (11), Mistral (11), Molokai (4), Aqua Inc, Koi |
| Брелоки | у каждой доски: 42 нарисованы по фото карточек (все Gladiator), остальные 56 — типовые, по общим правилам |
| Цвета | Artkal S, сняты с фото карточек; у 15 досок фото нет или оно неполное — они помечены «≈ цвета» |
| Наборы бусин | Artkal S, Hama midi, Perler, MARD — цвета переводятся в выбранный набор по ближайшему оттенку |
| Печать | A4, A3, Letter; шаг 2,6 / 5 / 10 мм; PDF одного листа или всех |

## Структура

```
index.html, styles.css, docs.html   страница приложения, стили, просмотр документации
js/                                 модули приложения (boot → palette → catalog → state → layout → draw → ui → app)
data/                               палитры, каталог досок, рисунки по фото, ключи цветов, переименования
tools/                              инструменты агента: фото из PDF, черновик сетки, цвета, листы сверки, тест
docs/                               документация
```

## Безопасность

- Сторонние библиотеки грузятся с cdnjs с включённым Subresource Integrity (jsPDF 4.2.1, marked 18.1.1, DOMPurify 3.4.17) — хеши закреплены в `index.html` и `docs.html`.
- Markdown из `docs/*.md` проходит через DOMPurify (с запретом `style`, `form`, `input`), прежде чем попасть в DOM; ссылки с небезопасными схемами удаляются.
- Из `localStorage` проверяются структура черновика и профилей, диапазоны настроек, id досок и цветов, число листов и досок на листе; словари палитры и каталога без прототипа.
- Python-инструменты в `tools/` разбирают недоверенные PDF и фото — запускайте их в отдельном venv или контейнере.
- Отчёты: [аудит №1](SECURITY-AUDIT.md) (до исправлений), [аудит №2](SECURITY-AUDIT-2.md) (после).

Принятые риски:

- CSP не задан: мета-политика сломала бы рантайм артефакта на claude.ai, а на GitHub Pages заголовки статикой не задаются. Ущерб ограничен: приложение не работает с чужими данными и не пересылает их.
- Google Fonts отдаёт IP и User-Agent посетителя в Google. Для полностью локального варианта нужно положить woff2 в репозиторий.
- Project-сайты `*.github.io` живут в одном origin: другой ваш Pages-проект видит `localStorage` этого. Снимается только отдельным доменом (CNAME).
- Библиотеки остаются на CDN (без локального вендоринга) — целостность держится на SRI.
