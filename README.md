# SUP-мозаика

Генератор трафаретов термомозаики для SUP-досок: полноразмерные модели и брелоки. Доски кладутся на поле штырьков, приложение считает бусины по цветам, рисует под них ячейки на свободном месте листа и сохраняет PDF для печати в масштабе 1:1.

Приложение: https://claude.ai/artifact/VMAbzmZZjhK3KREbrzP7yL · документация в нём же — ссылка «Документация» в шапке.

## Что внутри

| | |
|---|---|
| Доски | 104 полноразмерные модели 8 брендов: Gladiator (48), Aqua Marina (15), JS (13), Starboard (11), Mistral (11), Molokai (4), Aqua Inc, Koi |
| Брелоки | у каждой доски: 42 нарисованы по фото карточек (все Gladiator), остальные 56 — типовые, по общим правилам |
| Цвета | Artkal S, сняты с фото карточек; у 15 досок фото нет или оно неполное — они помечены «≈ цвета» |
| Наборы бусин | Artkal S, Hama midi, Perler, MARD — цвета переводятся в выбранный набор по ближайшему оттенку |
| Печать | A4, A3, Letter; шаг 2,6 / 5 / 10 мм; PDF одного листа или всех |

## Структура

```
index.html, styles.css, docs.html   страница приложения, стили, просмотр документации
js/                                 модули приложения (boot → palette → catalog → state → layout → draw → ui → app)
data/                               палитры, каталог досок, рисунки по фото, ключи цветов, переименования
tools/                              инструменты агента: фото из PDF, черновик сетки, цвета, листы сверки, тест
docs/                               документация
```
