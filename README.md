# SUP-мозаика

Генератор трафаретов термомозаики для SUP-досок: полноразмерные модели досок и брелоки. Доски кладутся на поле штырьков, приложение считает бусины по цветам, рисует под них ячейки на свободном месте листа и сохраняет PDF для печати в масштабе 1:1.

Приложение: https://akaguny.github.io/sup-mosaic/
